## Global components

Every page includes:

- Organisation branding and contact strip
- Main navigation with the current page identified
- Responsive mobile-menu button
- Main content divided into semantic sections
- Footer navigation, contact details and academic-project notice
- Shared responsive CSS and JavaScript files

## User journeys

1. A learner can move from Home to Programmes and then Contact to ask for information.
2. A potential mentor can move from Home to Get Involved and complete the demonstration application.
3. A partner can review About Us, explore Programmes and use Contact to make an enquiry.
